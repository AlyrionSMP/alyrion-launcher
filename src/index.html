Accounts

Log in with one of the supported providers. Tokens are stored locally; passwords are never saved.

Name must be 3–16 characters: letters, digits and underscores.

Sent to littleskin.cn over HTTPS (Yggdrasil).

Opens the Ely.by login page in your browser. After signing in there, this launcher receives the session automatically.

Set elyby_client_id + elyby_client_secret in settings.json — see README. Secret stays local, never in the binary.
